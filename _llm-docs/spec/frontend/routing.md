# ルーティング仕様

## 概要

**を使用したSPAルーティングの設計仕様です。

## ルーティング構成

### 基本構造

| ルートパス                  | ページコンポーネント | 説明                       |
| --------------------------- | -------------------- | -------------------------- |
| /                           | Home                 | ホーム             |

## 認証とナビゲーション

### 認証ルート
- `/login` は非認証で利用可能
- その他のルートは認証必須

### 認証ガード
- 未認証時は `/login` へリダイレクト

## エラーハンドリング

### 404エラー
- 未定義のパスは404ページ表示
- ダッシュボードへの戻るリンク提供

### 認証エラー
- トークン期限切れ時は再ログイン促進
- セッション維持の自動試行
