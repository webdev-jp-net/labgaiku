# Labが行く — Design System

> テキストの読み物を落ち着いて読むコンテンツが主軸。余白をふんだんに、十分な文字サイズ、余裕のあるブロッキング、ディテール装飾は最小限。

---

## 製品概要

**Labが行く** は、長文記事を中心とした日本語ウェブメディアです。「ラボ（研究室／実験の場）」という言葉が持つ知的で探究的な雰囲気と、「が行く」という道中・旅・能動の動きを重ねたネーミング。腰を据えて読ませる記事体験を第一に据えます。

**主要サーフェス**

- Webサイト（記事一覧 + 記事ページ）
- モバイルアプリ（記事を読むための専用クライアント）

**参照する読書体験**：note.comの「本文中心・余白豊か」な構造を基準に、より抑制を効かせた書籍的質感へ寄せます。

## 情報ソース

このデザインシステムはゼロから構築されています。ブランドは本プロジェクトが初期定義となります。外部の既存コードベースやFigmaの参照はありません。

## CONTENT FUNDAMENTALS

### 声・トーン

- **落ち着いた二人称。**「あなた」「〜してみてください」を基本に、押しつけがましくない敬体（です・ます調）。
- **編集者の声が薄く、主役は本文。** UI上のコピーは極力抑え、機能ラベルは体言止めを優先（「保存」「目次」「続きを読む」）。
- **比喩や詩的表現は本文に任せ、UIは事実を述べる。**「新着3件」であって「新着が届きました！」ではない。

### 人称・語彙

- **一人称：** 編集部・運営視点では「私たち」。筆者視点では「私」。
- **二人称：**「あなた」。
- **敬語：** 常体ではなく、常に敬体。ただし見出しでは体言止め多用。

### ケーシング・表記ルール

- **英数字は半角**（例：iPhone 15、2026年、Vol. 3）。
- **ブランド名は `Labが行く`** — `Lab` は半角、「が行く」は日本語のまま。スペースは入れない。
- **数字の桁区切り：** 3桁以上からカンマ（1,234）。
- **感嘆符・疑問符：** 本文では全角、UIでは使わない方針（叫ばない）。
- **鉤括弧：** 引用は「」、強調や作品名は『』。
- **三点リーダ：** 必ず全角2つ連続（……）。
- **ダーシ：** 全角二倍ダッシュ（——）。

### 絵文字・装飾

- **絵文字：使わない。**
- **記号：** 箇条書きは「・」または日本語向けの中黒を基本、必要なら `—`（em dash）。`*` や `•` は使わない。
- **装飾文字：不可。** 文字の大きさ・余白・行間で情報ヒエラルキーを構築する。

### コピー例

| シーン   | 推奨                             | 避ける                                |
| -------- | -------------------------------- | ------------------------------------- |
| 記事末尾 | 続きを読む →                     | 続きを読む！🎉                        |
| 空状態   | まだ何も保存していません         | 保存するものが見つかりませんでした 😢 |
| 新着通知 | 新しい記事が 3 件あります        | 新着が届きましたよ〜！                |
| 保存成功 | 保存しました                     | 保存完了 ✓ 素晴らしい！               |
| 記事冒頭 | 本記事は編集部の取材に基づきます | さあ、始めましょう！                  |

## VISUAL FOUNDATIONS

### 根本思想

**余白は最大の装飾。** 装飾要素を足す前に、余白を増やせるか考える。罫線は使うが極力1px・低コントラスト。シャドウは使わない。角丸はほぼゼロ。色は単色調で、差し色の概念自体をほぼ持たない。

### カラー

単色調（モノクローム）。ほぼ無彩色だけで成立させる。

- **紙色背景** `#fafaf7` — 純白を避けてわずかに温かみのある紙色。長時間読書で目が疲れにくい。
- **前景（本文）** `#1a1a1a` — 完全黒を避け、紙の上のインク感に近づける。
- **差し色は 1 つだけ許容：** インクブラック `#0a0a0a` を「読了チェック」等に使うが、彩度のある色は持たない。
- **ダークモード：** 背景 `#12120f`、前景 `#e8e6df`。純黒を避けて書籍的に。

### タイポグラフィ

- **書体：LINE Seed JP 一本。**
- **ウェイトは 2 種だけ：Thin（100）/ Regular（400）。Bold は使わない。**
- **ヒエラルキーはサイズ・余白・色で作る。** 太字に頼らない。
  - 大ディスプレイ・H1：Thin 100（余白を多く、大きく、細く）
  - H2・本文：Regular 400
  - 小見出し：Regular 400 + `letter-spacing` を広げてトラッキング強調、または色で差をつける
- **本文サイズ：16** 最低ラインは14。
- **行間：** 本文 `line-height: 1.9`。見出しは1.3〜1.5。
- **文字間：** 本文 `letter-spacing: 0.03em`、見出しは0.02em、トラッキング強調は0.12〜0.2em。
- **一行の文字数：** 50字を基準。
- **英数字のルール：** `font-feature-settings: "palt"` は不使用（プロポーショナルで詰めると本文が騒がしくなる）。見出しのみ必要に応じて許容。

### スペーシング

- **8の倍数グリッド** ただし、最少は4。縦方向は読書リズム優先で24/32/48/64/96が主。
- **ガター・セクション間：** 最低48、セクション区切りは96〜128。
- **コンテナー measure：** 58ch（fromWide）/ 100% - 32（narrow）。

### ボーダー・区切り

- **1px の実線のみ。** 色は `border-subtle`（#e4e2dc相当）。
- **区切り線は「節」単位でのみ使用。** 段落ごとに線を引かない。
- **装飾的なダブルラインや破線は使わない。**

### 角丸・形状

- **角丸は基本使用しない** UI要素（ボタン、入力欄）のみ2許容。カードには角丸を付けない（カードはそもそもほぼ使わない）。

### シャドウ・高さ

- **シャドウは使わない**
- **高さは余白と罫線のみで表現する**

### 背景・テクスチャ

- **無地のみ。** グラデーション不可。テクスチャ画像不可。パターン不可。
- **画像・イラスト：** 本デザインシステムでは「完全に文字のみ」の方針。記事本文内で著者が引用する画像の扱いは `<figure>` の素直な表示に限定。

### アニメーション

- **極少。** フェード（150ms / ease-out）と不透明度の変化のみ。
- **バウンス・弾性・パララックス・大きなスライドは使わない。**

### 透明度・ぼかし

- **Backdrop blur は使わない。**
- **オーバーレイは黒 40% 透過。**

### レイアウト規則

- **固定要素は持たない。** ヘッダー・フッター・目次のいずれも通常スクロール。スクロールに追従する固定要素は採用しない。
- **コンテンツは常に中央寄せ。** 左寄せレイアウトはヘッダー内の要素のみ。
- **段組みは 1 カラムを基本。** 記事一覧のみ必要に応じて2カラム。

### ボタン・カード

- **ボタン：** 塗りボタンと罫線ボタンの2種のみ。塗りは黒背景に紙色文字、罫線は1pxボーダー + 透明背景。
- **カード：** 原則カード化しない。記事リストは罫線区切り + 余白で表現する。ネイキッドなリストが基本。

## ICONOGRAPHY

### 基本方針

**アイコンは最小限。** 文字で伝えられるものは文字で伝える。アイコンは「文字だけでは視覚的に判別しづらい、繰り返し現れるUI要素」にのみ使用。

### 採用

- **Lucide Icons** をCDNから使用（細めの1.5ストローク、余白のあるジオメトリで本システムの余白主義と整合）。
  - CDN: `https://unpkg.com/lucide-static@latest/icons/`
  - ストロークは本システム内で `1.5` に統一。
- **Unicode 記号** を積極活用：`→`（続きを読む）、`←`（戻る）、`·`（区切り）、`——`（セクション区切り）、`¶`（段落マーク、フッター等）。

### 絵文字

- **使わない。**

### アイコン使用が妥当な場面

- 検索（`search`）
- メニュー（`menu`）
- 保存／ブックマーク（`bookmark`）
- 閉じる（`x`）
- 外部リンク（`arrow-up-right`）
- 共有（`share-2`）

### アイコン使用を避ける場面

- ナビゲーション文言の装飾（「ホーム」にハウス🏠アイコンを足すなど）
- 感情表現（絵文字は使わない）
- カテゴリマーカー（色や文字で表現する）

### ロゴ・ワードマーク

**テキストロゴのみ。** LINE Seed JP Regular（400）で `Labが行く` と組む。シンボルマークは持たない。アプリアイコンのみ、正方形内でワードマークを中央に配置したモノグラムを用意。
