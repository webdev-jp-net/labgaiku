# Labが行く—Design System

> テキストの読み物を落ち着いて読むコンテンツが主軸。余白をふんだんに、十分な文字サイズ、余裕のあるブロッキング、ディテール装飾は最小限。

---

## 製品概要

**Labが行く**は、長文記事を中心とした日本語ウェブメディアです。「ラボ（研究室／実験の場）」という言葉が持つ知的で探究的な雰囲気と、「が行く」という道中・旅・能動の動きを重ねたネーミング。腰を据えて読ませる記事体験を第一に据えます。

**主要サーフェス**

- Webサイト（記事一覧+記事ページ）
- モバイルアプリ（記事を読むための専用クライアント）

**参照する読書体験**：note.comの「本文中心・余白豊か」な構造を基準に、より抑制を効かせた書籍的質感へ寄せます。

## 情報ソース

このデザインシステムはゼロから構築されています。ブランドは本プロジェクトが初期定義となります。外部の既存コードベースやFigmaの参照はありません。

## CONTENT FUNDAMENTALS

### 声・トーン

- **落ち着いた二人称。**「あなた」「〜してみてください」を基本に、押しつけがましくない敬体（です・ます調）。
- **編集者の声が薄く、主役は本文。**UI上のコピーは極力抑え、機能ラベルは体言止めを優先（「保存」「目次」「続きを読む」）。
- **比喩や詩的表現は本文に任せ、UIは事実を述べる。**「新着3件」であって「新着が届きました！」ではない。

### 人称・語彙

- **一人称：**編集部・運営視点では「私たち」。筆者視点では「私」。
- **二人称：**「あなた」。
- **敬語：**常体ではなく、常に敬体。ただし見出しでは体言止め多用。

### ケーシング・表記ルール

- **英数字は半角**（例：iPhone 15、2026年、Vol. 3）。
- **ブランド名は`Labが行く`**—`Lab`は半角、「が行く」は日本語のまま。スペースは入れない。
- **数字の桁区切り：**3桁以上からカンマ（1,234）。
- **感嘆符・疑問符：**本文では全角、UIでは使わない方針（叫ばない）。
- **鉤括弧：**引用は「」、強調や作品名は『』。
- **三点リーダ：**必ず全角2つ連続（……）。
- **ダーシ：**全角二倍ダッシュ（——）。記事タイトルや見出しに含まれた`——`はサブタイトルの区切りとして扱い、`<small>`で囲って従属表示する。詳細は[インタビュー記事整形仕様](./frontend/interview-render.md)。

### 絵文字・装飾

- **絵文字：使わない。**
- **記号：**箇条書きは「・」または日本語向けの中黒を基本、必要なら`—`（em dash）。`*`や`•`は使わない。
- **装飾文字：不可。**文字の大きさ・余白・行間で情報ヒエラルキーを構築する。

### コピー例

| シーン   | 推奨                             | 避ける                               |
| -------- | -------------------------------- | ------------------------------------ |
| 記事末尾 | 続きを読む→                      | 続きを読む！🎉                       |
| 空状態   | まだ何も保存していません         | 保存するものが見つかりませんでした😢 |
| 新着通知 | 新しい記事が3件あります          | 新着が届きましたよ〜！               |
| 保存成功 | 保存しました                     | 保存完了✓素晴らしい！                |
| 記事冒頭 | 本記事は編集部の取材に基づきます | さあ、始めましょう！                 |

## VISUAL FOUNDATIONS

### 根本思想

**余白は最大の装飾。**装飾要素を足す前に、余白を増やせるか考える。罫線は使うが極力1px・低コントラスト。シャドウは使わない。角丸はほぼゼロ。色は単色調で、差し色の概念自体をほぼ持たない。

### カラー

紙色をベースとした抑制的な配色。テキストはコントラスト5階調を持ち、強調マーカー用途のみ薄く彩度のあるアクセントを許容する。

#### 背景

- **`--bg-basic`**ライト`#fafaf7`／ダーク`#12120f`—純白・純黒を避け、紙とインクの質感に近づける。
- **`--bg-accent`**ライト`#90d5cc`／ダーク`#427e8a`—くすみ系ティール。背景帯マーカー（`--border-marker`）の生成にのみ用いる差し色で、ベタ塗りでは使わない。

#### テキスト（コントラスト5階調）

| トークン        | ライト    | ダーク    | 用途                                       |
| --------------- | --------- | --------- | ------------------------------------------ |
| `--txt-accent`  | `#1a1a1a` | `#e8e8df` | 見出し・本文中の強調                       |
| `--txt-basic`   | `#4a4845` | `#c1c0b8` | 本文                                       |
| `--txt-muted`   | `#85827a` | `#77756e` | 補足説明（`txt-description`）              |
| `--txt-subtle`  | `#b8b5ac` | `#4a4845` | カナ表記・補助情報、ボーダー生成元         |
| `--txt-on-fill` | `#fafaf7` | `#12120f` | 反転背景に置く文字（塗りボタン文字色など） |

#### ボーダー

- **`--border-basic`**=`--txt-subtle`を50%透過。紙色背景に対して低コントラストで馴染む1pxの罫線。
- **`--border-marker`**=`--bg-accent`を50%透過。`txt-marker`mixinの背景帯に使用。

### タイポグラフィ

- **書体：LINE Seed JP一本。**
- **ウェイトは2種だけ：Thin（100）／Regular（400）。Boldは使わない。**
- **ヒエラルキーはサイズ・余白・色で作る。**太字に頼らない。
  - 大ディスプレイ（`hd-display`）：Thin 100、`rem(56)`〜`rem(80)`（narrow／fromWide）
  - 大見出し（`hd-lg`）：Thin 100、`rem(42)`〜`rem(48)`
  - 中見出し（`hd-md`、本文`<h2>`）：narrowはRegular 400／fromWideはThin 100、`rem(32)`
  - 小見出し（`hd-sm`、本文`<h3>`）：Regular 400、`rem(24)`
  - リード（`txt-lead`）：Regular 400、`rem(18)`
  - 本文（`txt-paragraph`）：Regular 400、`rem(16)`
- **画面幅で太さを切り替える見出し：**narrowではRegularで芯のある印象、fromWideではThinに切り替えて余白に溶ける質感へ寄せる（`hd-md`／`hd-lg`／本文`<h2>`のsmall部分）。
- **本文サイズ：**ベース`rem(16)`。最低ラインは14。
- **行間：**本文はnarrow`2.0`、fromWide`2.5`。見出しは`1.3`〜`1.5`。
- **文字間：**
  - 本文：`letter-spacing: 0.04em`
  - 中・大見出し（`hd-md`／`hd-lg`）：`0.02em`
  - 小見出し・大ディスプレイ（`hd-sm`／`hd-display`）：`0.03em`
  - リード：`0.05em`
- **英数字のルール：**`font-feature-settings: "palt"`を有効化する（`body`に適用）。プロポーショナル詰めで日本語と英数字が混在する見出しの密度感を整える。

### スペーシング

- **4を最少とする8の倍数グリッド。**縦方向は読書リズム優先で`24/32/48/64/96`が主軸、ヒーローやセクション間は`128/160/200`を組み合わせる。
- **トークン：**`--spacing-xs (4)`／`sm (8)`／`md (24)`／`lg (32)`／`xl (40)`／`2xl (48)`／`3xl (64)`／`4xl (96)`／`5xl (128)`／`6xl (160)`／`7xl (200)`。`md`は`16`を飛ばして`24`に置き、本文の段落間とブロック間の差を確保する。
- **ガター・セクション間：**最低`48`、セクション区切りは`96`〜`128`、ヒーロー上下や独立ブロックは`160`〜`200`。
- **コンテナーmeasure：**narrowは`100% - var(--spacing-md) × 2`、fromWideは`max-width: rem(600)`+左右`var(--spacing-xl)`パディング。

### ボーダー・区切り

- **1pxの実線のみ。**色は`--border-basic`（`--txt-subtle`を50%透過した値で、紙色背景に低コントラストで馴染む）。
- **区切り線は「節」単位でのみ使用。**段落ごとに線を引かない。
- **装飾的なダブルラインや破線は使わない。**
- **マーカー：**強調マーカーは`--border-marker`（`--bg-accent`を50%透過した値）を背景帯として`txt-marker`mixinで適用。

### 角丸・形状

- **角丸は基本使用しない。**UI要素（ボタン、入力欄）のみ2許容。カードには角丸を付けない（カードはそもそもほぼ使わない）。

### シャドウ・高さ

- **シャドウは使わない。**
- **高さは余白と罫線のみで表現する。**

### 背景・テクスチャ

- **無地のみ。**グラデーション不可。テクスチャ画像不可。パターン不可。
- **画像・イラスト：**本デザインシステムでは「完全に文字のみ」の方針。記事本文内で著者が引用する画像の扱いは`<figure>`の素直な表示に限定。

### アニメーション

- **極少。**トランジションは`--transition: 150ms ease-out`を共通基準にし、不透明度・色・背景位置などの軽量プロパティに限定する。
- **バウンス・弾性・パララックス・大きなスライドは使わない。**
- **ホバー演出：**`(any-hover: hover)`ガードを噛ませ、テキストリンクの下線伸縮や色の濃淡変化など読書を阻害しない範囲で行う。

### 透明度・ぼかし

- **Backdrop blurは使わない。**
- **オーバーレイは黒40%透過。**

### レイアウト規則

- **`position: fixed`は使わない。**画面に貼り付くようなオーバーレイは持たない。
- **`position: sticky`は読書補助用途に限定して許容。**fromWideで詳細ページの左サイドパネル（タイトル・ゲスト・日付・MemberList・IndexNavigation）を画面内に追従させる用途、および一覧ページのインデックス領域に使う。narrowではstickyを解除し通常スクロール。
- **コンテンツは常に中央寄せ。**左寄せレイアウトはヘッダー内の要素のみ。
- **段組み：**narrowは1カラム。fromWideでは詳細ページ・一覧ページとも左サイド固定領域+本文の2カラムgridを採用する。

### ボタン・カード

- **ボタン：**塗りボタンと罫線ボタンの2種のみ。塗りは黒背景に紙色文字、罫線は1pxボーダー+透明背景。
- **カード：**原則カード化しない。記事リストは罫線区切り+余白で表現する。ネイキッドなリストが基本。

## ICONOGRAPHY

### 基本方針

**アイコンは最小限。**文字で伝えられるものは文字で伝える。アイコンは「文字だけでは視覚的に判別しづらい、繰り返し現れるUI要素」にのみ使用。

### 採用

- **Lucide Icons**をCDNから使用（細めの1.5ストローク、余白のあるジオメトリで本システムの余白主義と整合）。
  - CDN：`https://unpkg.com/lucide-static@latest/icons/`
  - ストロークは本システム内で`1.5`に統一。
- **Unicode記号**を積極活用：`→`（続きを読む）、`←`（戻る）、`·`（区切り）、`——`（セクション区切り）、`¶`（段落マーク、フッター等）。

### 絵文字

- **使わない。**

### アイコン使用が妥当な場面

- 検索（`search`）
- メニュー（`menu`）
- 保存／ブックマーク（`bookmark`）
- 閉じる（`x`）
- 外部リンク（`arrow-up-right`）
- 共有（`share-2`）

### アイコン使用を避ける場面

- ナビゲーション文言の装飾（「ホーム」にハウス🏠アイコンを足すなど）
- 感情表現（絵文字は使わない）
- カテゴリマーカー（色や文字で表現する）

### ロゴ・ワードマーク

**テキストロゴのみ。**LINE Seed JP Regular（400）で`Labが行く`と組む。シンボルマークは持たない。アプリアイコンのみ、正方形内でワードマークを中央に配置したモノグラムを用意。
