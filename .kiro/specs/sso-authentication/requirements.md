# 要件定義書

## 概要

TAMSAN Labの「Labが行く」プロジェクトにおいて、セキュアなシングルサインオン（SSO）認証システムを実装し、認証されたユーザーのみがインタビュー記事にアクセスできるようにする機能です。Auth.jsを使用してGoogle OAuthとGitHub OAuthによる認証を提供します。

## 要件

### 要件1：SSOプロバイダーによる認証

**ユーザーストーリー：** TAMSAN Labのメンバーとして、GoogleアカウントまたはGitHubアカウントを使用してログインできるようにしたい。これにより、新しいパスワードを覚える必要がなく、セキュアにアクセスできる。

#### 受入基準

1. WHEN ユーザーがログインページにアクセスした時 THEN システムはGoogleとGitHubのログインオプションを表示する
2. WHEN ユーザーがGoogleログインボタンをクリックした時 THEN システムはGoogle OAuth認証フローを開始する
3. WHEN ユーザーがGitHubログインボタンをクリックした時 THEN システムはGitHub OAuth認証フローを開始する
4. WHEN OAuth認証が成功した時 THEN システムはユーザーセッションを作成し、記事一覧ページにリダイレクトする
5. WHEN OAuth認証が失敗した時 THEN システムはエラーメッセージを表示し、ログインページに留まる

### 要件2：セッション管理とアクセス制御

**ユーザーストーリー：** 認証されたユーザーとして、ログイン状態を維持し、保護されたページに継続的にアクセスできるようにしたい。また、必要に応じてログアウトできるようにしたい。

#### 受入基準

1. WHEN ユーザーが認証された時 THEN システムはセキュアなセッションCookieを設定する
2. WHEN 認証されたユーザーが保護されたページにアクセスした時 THEN システムはセッションを検証してアクセスを許可する
3. WHEN 未認証ユーザーが保護されたページにアクセスした時 THEN システムはログインページにリダイレクトする
4. WHEN ユーザーがログアウトボタンをクリックした時 THEN システムはセッションを無効化し、ログインページにリダイレクトする
5. WHEN セッションが期限切れになった時 THEN システムは自動的にログインページにリダイレクトする

### 要件3：保護されたページの実装

**ユーザーストーリー：** システム管理者として、記事一覧ページと記事詳細ページを認証されたユーザーのみがアクセスできるように制限したい。これにより、コンテンツのセキュリティを確保できる。

#### 受入基準

1. WHEN 未認証ユーザーが記事一覧ページ（/articles）にアクセスした時 THEN システムはログインページにリダイレクトする
2. WHEN 未認証ユーザーが記事詳細ページ（/articles/[slug]）にアクセスした時 THEN システムはログインページにリダイレクトする
3. WHEN 認証されたユーザーが記事一覧ページにアクセスした時 THEN システムは記事一覧を表示する
4. WHEN 認証されたユーザーが記事詳細ページにアクセスした時 THEN システムは記事内容を表示する
5. WHEN 認証されたユーザーがトップページ（/）にアクセスした時 THEN システムは記事一覧ページにリダイレクトする

### 要件4：ユーザー情報の表示

**ユーザーストーリー：** ログインしたユーザーとして、ヘッダーに自分のプロフィール情報（名前、アバター）とログアウトボタンが表示されるようにしたい。これにより、現在のログイン状態を確認できる。

#### 受入基準

1. WHEN 認証されたユーザーがページを表示した時 THEN システムはヘッダーにユーザー名を表示する
2. WHEN 認証されたユーザーがページを表示した時 THEN システムはヘッダーにユーザーのアバター画像を表示する
3. WHEN 認証されたユーザーがページを表示した時 THEN システムはヘッダーにログアウトボタンを表示する
4. WHEN 未認証ユーザーがログインページを表示した時 THEN システムはヘッダーにログインボタンのみを表示する

### 要件5：エラーハンドリングとユーザビリティ

**ユーザーストーリー：** ユーザーとして、認証プロセスで問題が発生した場合に、分かりやすいエラーメッセージが表示され、適切な対処方法が示されるようにしたい。

#### 受入基準

1. WHEN OAuth認証でネットワークエラーが発生した時 THEN システムは「接続に問題が発生しました。しばらく待ってから再試行してください。」というメッセージを表示する
2. WHEN OAuth認証でユーザーがキャンセルした時 THEN システムは「ログインがキャンセルされました。」というメッセージを表示する
3. WHEN セッション期限切れが発生した時 THEN システムは「セッションが期限切れです。再度ログインしてください。」というメッセージを表示する
4. WHEN 認証サーバーでエラーが発生した時 THEN システムは「認証サービスに問題が発生しています。しばらく待ってから再試行してください。」というメッセージを表示する
5. WHEN 認証が成功した時 THEN システムは「ログインしました。」という成功メッセージを短時間表示する
