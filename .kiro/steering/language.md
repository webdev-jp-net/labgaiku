# 言語設定

## 基本方針

このプロジェクトでは、すべてのコミュニケーションとドキュメント作成において**日本語**を使用します。

## 適用範囲

### チャット・コミュニケーション
- AI開発者とのやり取りは日本語で行う
- 質問・回答・説明はすべて日本語
- エラーメッセージや警告も可能な限り日本語で表示

### ドキュメント作成
- 仕様書・設計書は日本語で記述
- コメント・説明文は日本語
- README、ガイドライン等も日本語

### コード内での言語使用
- **変数名・関数名**: 英語（技術的な慣習に従う）
- **コメント**: 日本語
- **ログメッセージ**: 日本語
- **エラーメッセージ**: 日本語

## 例外事項

以下の場合は英語の使用を許可します：
- 技術的な専門用語（API、HTTP、JSON等）
- ライブラリ・フレームワークの固有名詞
- 国際的な標準規格に関する用語
- GitHubのIssue・PRで英語圏の開発者との協業が必要な場合

## 実装ガイドライン

```typescript
// ✅ 良い例
const articleList = getArticleList(); // 変数名は英語
// 記事一覧を取得する処理 // コメントは日本語

// ❌ 避ける例
const kijichiran = getArticleList(); // 変数名の日本語ローマ字は避ける
// Get article list // コメントの英語は避ける
```

## AI開発者への指示

- 必ず日本語でコミュニケーションを行ってください
- 技術的な説明も日本語で分かりやすく行ってください
- 英語のドキュメントを参照する場合は、要点を日本語で要約してください
